# Piblo Build Ledger

Authoritative engineering record for the Piblo ecosystem (`manazoid4/piblo`, `manazoid4/piblo-private`, PibloCraft, Piblo Core, Flow, and companion apps).

## Purpose
This ledger tracks verified engineering work, architectural decisions, dependencies, integration maps, active blockers, and testing batches across the Piblo ecosystem. It complements unified memory (`unified-memory-database`) and serves as the operational source of truth for autonomous agents and developers working on Piblo.

## Conventions
- Every meaningful feature or sub-system change must be recorded in `features/YYYY-MM-DD-feature-name.md`.
- Updates to queues and state must be reflected in `BUILD-QUEUE.md` and `CURRENT-STATE.md`.
- All code references must link to real branches, commits, or PRs.
