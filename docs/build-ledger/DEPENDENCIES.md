# Piblo Dependencies & Requirements

## Hardware
- ESP32-S3 microcontroller boards (Waveshare, Cardputer ADV, custom portrait retro enclosure).
- Windows host PC / Android companion devices.

## Software & Libraries
- Python 3.10+ / Node.js / PlatformIO for firmware builds.
- Local speech-to-text engines (Piblo Flow).
- Optional local models (FunctionGemma, Qwen small variants via Ollama / local inference).
- OCR engines (RapidOCR / PaddleOCR / Tesseract fallback).
