# PibloCraft, 30 second video script

Format: screen capture of a real terminal session, voiceover or captions. No music needed. Record the real thing; do not use the illustration as footage.

| Time | On screen | Voiceover or caption |
| --- | --- | --- |
| 0-4s | Empty terminal. Type `pc`. Three panes open, each with a numbered agent menu. | "Running more than one coding agent gets messy." |
| 4-10s | Pick Claude, Codex and Hermes, one per pane. Usage left shows in each menu. | "PibloCraft puts them side by side. You pick the agent for each pane." |
| 10-17s | Type `pc "Improve the README for 2 hours"`. The panes start working. | "Give it a job in plain words. Or a whole shift." |
| 17-24s | Type `pc ?`. The short status appears, one agent shows waiting for you. | "One line tells you who is working and who is waiting for you." |
| 24-28s | Type `pc answer`. Answer one decision. | "Answer the decision. The agent carries on." |
| 28-30s | End card: PibloCraft, piblo.co.uk/piblocraft, "Early access". | "PibloCraft. Early access at piblo dot co dot uk." |

Notes
- Show only what is real on the day you record. If a pane fails to start, cut it and say less.
- Keep the repo and folder names generic on screen. Nothing personal in the terminal prompt or paths.
- Captions on, because most people watch muted.
