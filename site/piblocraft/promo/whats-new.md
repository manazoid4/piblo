# What's new in PibloCraft

**PibloCraft is the new name.** The commands are `pc` and `piblocraft`.

- **20 more model providers.** DeepSeek, Kimi, GLM, MiniMax, Qwen, OpenRouter, Together, Fireworks, SiliconFlow, Ollama and LM Studio run inside Claude Code. Nous, Groq, NVIDIA, Cerebras, Gemini, Mistral and xAI run in Hermes. Save a key once with `pc key <name>`.
- **A smarter pane menu.** Each agent shows live state (`62% left`, `back 02:49`, `sign in again`), the best one is starred, and Enter starts it.
- **Better status.** `pc ?` says what you can use right now: each Claude's real usage, the best one, and which other models are ready.
- **See and ship a task.** `pc diff` shows what a night task changed. `pc ship` commits and pushes its branch.
- **Safer by default.** Nothing starts on its own. Auto-approval for commands is off unless you turn it on.
- **Auto-update.** Pane menus pull new versions hourly, fast-forward only.

Early access: piblo.co.uk/piblocraft
